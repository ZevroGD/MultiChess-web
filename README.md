# MultiChess Web

A browser-based version of MultiChess. The page provides the chess interface and connects to the project's WebSocket game server for online play.

## Play

Open the GitHub Pages site:

https://zevrogd.github.io/MultiChess-web/

A live server connection is required for online multiplayer. The connection indicator in the page shows whether the client is connected.

## Project files

- `index.html`: the complete browser client, including its styles and game logic.
- `chess/`: sound effects used by the client.

There is no separate frontend build step. Changes to `index.html` can be tested by reloading the page.
